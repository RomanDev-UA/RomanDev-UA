# 🛠️ RomanDev AI: Система автоматизации смет

Проект на Python для автоматизации расчетов материалов и создания отчетов в формате Excel.

### 🚀 Что умеет агент:
* **Калькуляция:** Автоматически считает общую стоимость (Кол-во × Цена).
* **Excel-отчеты:** Генерирует готовые таблицы `.xlsx` с итоговой суммой.
* **Авто-именование:** Файлы сохраняются с текущей датой и временем.
* **Журнал событий:** Ведется лог всех действий в `history.log`.

### 🧰 Технологический стек:
* **Python 3.10+**
* **Pandas & Openpyxl** (Работа с данными)
* **Google Gemini API** (Искусственный интеллект)
* **Git & GitHub** (Версионность)

---
*Проект находится в активной разработке. Цель: Полная автоматизация строительных и сварочных расчетов в г. Полтава.*
